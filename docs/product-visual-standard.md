# 小程序商品视觉规范

P2 前端已经使用统一品牌商品封面组件。即使后台暂时没有上传图片，也会使用绿色、金色、玫红或蓝色品牌渐变生成可读封面；上传正式素材后自动替换为图片版本。

## 封面图

- 推荐尺寸：`1200 × 1200 px`；
- 比例：`1:1`；
- 格式：JPG 或 WebP；
- 单图建议小于 500 KB；
- 主要人物、武器或吉祥物放在画面中上部；
- 底部 35% 不放关键文字，前端会叠加商品名称和简介；
- 左上角预留品牌区，右上角预留销量标签区；
- 不要把价格直接写死在图片中，价格以后端规格为准。

## 轮播图

- 推荐尺寸：`1200 × 900 px`；
- 比例：`4:3`；
- 每个商品 2–5 张；
- 第一张突出核心服务，后续图片分别介绍流程、时效、保障和注意事项。

## 详情长图

- 推荐宽度：`750 px`；
- 高度不限，建议单张不超过 3000 px；
- 每张建议小于 1 MB；
- 推荐结构：服务价值 → 套餐差异 → 下单流程 → 规则说明 → 售后保障；
- 文字字号按 750 px 宽图至少使用 26 px，避免真机不可读。

## 品牌颜色

- 主绿色：`#1F7C4B`；
- 深绿色：`#173426`；
- 金色：`#D8A144`；
- 浅金色：`#F3D79B`；
- 趣味单玫红：`#E65F75`；
- 特色单蓝色：`#4B91BE`；
- 页面背景：`#F5F7F3`。

商品类型对应主题：

| 商品类型 | 前端主题 |
|---|---|
| 普通陪玩 | 绿色 |
| 保底单 | 金色 |
| 趣味单 | 玫红 |
| 特色单 | 蓝色 |

## 上架前检查

运行：

```bash
python manage.py audit_product_assets
```

严格检查并在 CI/发布流程中失败：

```bash
python manage.py audit_product_assets --fail-on-warning
```

自动下架素材或价格不完整的商品：

```bash
python manage.py audit_product_assets --deactivate-incomplete
```

上架商品至少需要：

1. 一张封面图；
2. 商品简介；
3. 详情长图或详情文字；
4. 大于 0 的基础价格或全部有效规格价格。
